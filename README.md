# 💃 DanceVault

### Dance Practice & Progress Tracker

DanceVault is a simple web application that helps dancers organize their dance routines and track their practice progress in one place.

## ✨ Features

* 🎵 Add dance routines
* ✏️ Edit routines
* 🗑️ Delete routines
* 🎯 Set practice goals
* 📊 Track practice progress
* 📅 Save practice dates
* 📝 Add practice notes
* 🎬 Add YouTube tutorial links
* 🔍 Search routines
* 🎚️ Filter routines by difficulty
* 🔥 Practice streak tracking
* 🏆 Achievement system
* 📈 Progress overview chart
* 🌙 Dark / Light mode
* 💾 Data saved using LocalStorage

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* LocalStorage

## 🎯 Purpose

DanceVault was created to make dance practice more organized and motivating by combining routine management, progress tracking, goals, and achievements into one application.
